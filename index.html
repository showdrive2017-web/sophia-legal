SOPHIA プライバシーポリシー

最終更新日:2026年11月13日

Yoshinori Kusakari（草苅佳宣、以下「当方」）は、ストーリー構築アプリ「SOPHIA」（以下「本アプリ」）における 利用者の情報の取り扱いについて、次のとおり定めます。

1. 収集する情報

ひとりで使う星空

あなたが作る作品（星のタイトル・本文・つながり・メモ・埋め込んだ画像）は、お使いの端末の中だけに保存します。当方のサーバーにも、第三者にも送りません。

「同じ空」（仲間を招く・招かれる機能）

仲間といっしょに使う星空は、端末の中ではなく、当方が利用するサーバーに保存します。この機能を使わなければ、サーバーには何も送られません。保存するのは次のものです。

保存するもの何のために
自動で作られる利用者の番号（名前やメールアドレスとは結びつきません）誰の星かを見分け、本人だけが自分の星を書きかえられるようにするため
あなたが入力した名前、選んだ色星空の仲間に、誰の星かを見せるため
「同じ空」に書いた星（タイトル・本文・日付・時刻）、星の場所、線仲間全員の画面に同じ星空を出すため
いま星空を開いているかどうか、参加した日時、参加に使った招待コード「オンライン」の表示と、招待の管理のため
招待コードを調べた記録（コードと時刻）招待コードの総当たりを防ぐため
購入を確かめた記録（ストアの購入番号、または購入の証明から作った符号。カード番号などの決済情報は含みません）製品版の機能（仲間を招く、4 つ以上の星を生む）を使えるかを確かめるため
通報の記録（通報された星や名前の写し、通報した人の利用者の番号、理由）通報を確認し、対応するため
  • 「同じ空」に書いたことは、その星空の仲間全員（最大 6 人）に見えます。
  • メールアドレス、電話番号、位置情報、連絡先、広告用の ID は集めません。ログインも求めません。
  • サーバーは Google LLC の Firebase（Realtime Database はシンガポール、利用者の番号の管理は米国、購入の確かめ・通報・削除の処理は日本）を使っています。通信の際、接続元の IP アドレスなどが Google の設備で処理されます（Google のプライバシーポリシー）。
  • 当方は、通報を受けたとき、不具合の調査、法令にもとづく求めがあったときに限り、「同じ空」の内容を確認することがあります。広告や分析のために中身を使うことはありません。

全体要約機能（PC版のみ）

利用者自身が用意した API キーを使って、星の名前と中身を Anthropic 社（Claude を提供する会社）に送信し、要約を受け取ります。この機能は利用者が自分の意思で 使う場合にのみ働き、使わなければ何も送信されません。API キーは端末のブラウザ内にのみ保存されます。

2. 広告

本アプリは広告を表示しません。

3. アプリ内購入

本アプリには、星の数の制限を外すための買い切り商品があります。価格はストアの購入画面に表示されます。購入手続きは Google Play / Apple App Store が扱い、クレジットカード番号などの決済情報は当方には渡りません。 当方が受け取るのは「購入済みかどうか」という状態のみです。

「同じ空」では、製品版かどうかを確かめるために、ストアが発行する購入の証明を当方のサーバーに送り、Apple または Google に照会します。カード番号などの決済情報は、これまでどおり当方には渡りません。

4. 分析・広告目的のトラッキング

本アプリは、利用状況を集計する分析ツール（アクセス解析など）を組み込んでいません。

なお、本アプリの公式サイト（sophia-universe.com）では、広告の効果を測るために、Google LLC の計測タグ（Google タグ）を使っています。 サイトを見たときに、ページを見たことや、App Store・Google Play・PC版ダウンロードへのリンクが押されたことなどの情報が、 クッキーなどを通じて Google に送られます。この情報は、どの広告からアプリの入手に進んだかを数えるために使います。 あなたの名前やメールアドレスは送られません。アプリの中では、この計測は行いません。

  • 送信先:Google LLC（Google のプライバシーポリシー）
  • 止める方法:Google の広告設定で広告のカスタマイズをオフにするか、ブラウザでクッキーを無効にしてください。
  • 欧州経済領域・英国・スイスからのアクセスでは、同意がない限り、広告用のクッキーを使いません。

また、公式サイトでは、ページの閲覧数を数えるために、Cloudflare, Inc. のアクセス解析（Cloudflare Web Analytics）を使っています。見られたページ、参照元、ブラウザの種類などの情報が Cloudflare に送られます。あなたの名前やメールアドレスは送られません。アプリの中では、この計測も行いません。

  • 送信先:Cloudflare, Inc.（Cloudflare のプライバシーポリシー）

5. お子様のプライバシー

本アプリは、13 歳未満のお子様を主な対象として作られたものではなく、お子様の情報を意図的に収集することはありません。「同じ空」は、13 歳以上の方が対象です。

6. データの削除

  • ひとりで使う星空：端末の中だけにあるので、アプリ内の「削除」またはアプリのアンインストールで、いつでも消せます。
  • 「同じ空」：
    • 自分の星は、いつでも自分で消せます。
    • アプリの設定の「同じ空のデータを削除」で、あなたが書いた星・名前・色・参加の記録・購入を確かめた記録・利用者の番号を、サーバーからまとめて消せます。あなたがホストの星空は、星空ごと消えます。
    • アプリを消してしまったあとでも、データの削除の窓口から依頼できます。
    • 誰も開かなくなった星空は、最後に開かれてから 180 日で、サーバーから自動で消します。
    • 通報の記録は、対応のために残すことがあります。
    • ほかの人がすでに保存した写しやスクリーンショットまでは、当方から消すことはできません。

7. このポリシーの変更

機能の追加に伴い、本ポリシーの内容は更新されることがあります。 重要な変更がある場合は、更新日をこのページの先頭に明記します。
